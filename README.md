# AutoScreenRecorder

AutoScreenRecorder 在 Windows 后台帮你录屏幕。它没有窗口，也不用你去按开始或停止。

你在配置里写下要盯着的软件。这些软件只要占用了系统当前的默认麦克风，录制就会开始；等它们把麦克风放开，录制停止，这一段存成一个视频。示例里写的是飞书（`Lark.exe` 和 `Feishu.exe`）。你可以改成别的会议软件或语音软件，也可以同时写好几个。名字用任务管理器里看到的那个，比如 `Zoom.exe`。

在软件里把自己静音，通常只是不再把声音送出去，麦克风多半还被这个软件占着，所以录制会继续。等它真正放开麦克风，录制才停止，文件才会保存。

视频默认放在「视频」文件夹里。保存之后，右下角会弹出一条通知，点一下就能在文件夹里找到这个文件。

## 它解决什么问题

打电话、开会的时候，很容易忘了按录制，也容易把开始前和结束后的桌面一起录进去。把开关交给「有没有占用麦克风」，留下来的就是这段真正在用麦克风的时间。

规则就这几条：

- 只有你写进名单的软件会触发录制。没写进去的软件即使用了麦克风，也不会录。
- 可以再写一份排除名单。改系统麦克风时，系统设置经常会短暂占用设备，把它排除掉，就不会误录。
- 同一个软件如果同时占着好几路麦克风，要等这些路全部放开，才算结束。
- 开始和停止都可以各等几秒，免得软件刚碰上麦克风又马上放开，留下一两秒的废片。
- 从占用到放开，写成一个文件。鼠标移到另一块屏幕，还是录在这同一个视频里。
- 录完会通知你。点通知，文件夹会打开，并选中这个视频。

## 什么时候开始，什么时候停止

程序看的是 Windows 声音设置里，当前选中的那个麦克风。

名单里的软件一开始用它，录制就开始。你要是设了「过几秒再开始」，就先等完这几秒。等到一半软件已经放开麦克风，这次就不录。

软件放开麦克风后，录制结束，文件保存下来。你要是设了「过几秒再停止」，就先等完再保存。这几秒里软件又用上了麦克风，就接着录，先不保存。

换了默认麦克风，或者把麦克风拔掉，程序仍在后台跑。有新的默认麦克风，就改看新的。一时没有麦克风，大约每两秒再看一次。

电脑上同时只开一份软件。再双击一次软件，新开的软件会马上关掉。

## 画面和声音

录的是你眼前的桌面，鼠标在哪块屏幕上，就录哪块屏幕，鼠标箭头也会画进画面里。

「跟着鼠标」开着时，视频尺寸按最大的那块屏幕来。较小的屏幕会按同一比例放大或缩小，完整放进这个画面，不裁掉，也不拉变形。宽高比一样就铺满；不一样时，黑边只出现在上下两边，或者左右两边。鼠标移到另一块屏幕，画面会跟着过去，整段仍是一个视频：

![跟随鼠标在多块屏幕之间录制](https://github.com/user-attachments/assets/9759f01c-bc58-47bb-99aa-59933662cd16)

关掉「跟着鼠标」之后，整段视频都固定在刚开始录时光标所在的那块屏幕。

如果觉得视频太大，可以限制画面的宽度和高度，程序会按比例缩小。两项都填 0，就按屏幕原来的大小录。

声音默认有两路：电脑放出来的声音，以及麦克风里的声音，混在一条音轨里。两路都可以单独关掉，也可以分别调大或调小。录到一半时，你如果更换了系统默认的喇叭或麦克风，录音会跟着换过去。

声音是立体声，音质固定，不用在配置里改。保存成 MP4 时用 AAC，保存成 WMV 时用 WMA。

如果 Windows 禁止本程序使用麦克风，它就既录不到麦克风，也看不到谁在占用麦克风，录制不会开始。到「设置 → 隐私和安全性 → 麦克风」里允许它。

## 视频存在哪里

默认位置是：

```text
C:\Users\你的用户名\Videos\AutoScreenRecorder
```

文件名类似 `202610082222_Lark.mp4`。前面是开始录制的时间，精确到分钟；后面是触发这次录制的软件名。同一分钟里又录了一次，不会覆盖上一份，会自动变成 `……_2`、`……_3`。

文件夹不存在时会自动建好。扩展名也会跟你选的格式对齐：选了 MP4，就算文件名写成 `.wmv`，最后仍是 `.mp4`。

仓库里准备了三份现成配置，复制一份来用就行：

| 文件 | 适合 | 格式 | 流畅度 | 文件大小 |
| --- | --- | --- | --- | --- |
| `config.example.balanced.yaml` | 日常使用，推荐 | MP4 | 每秒 24 张 | 中等 |
| `config.example.faststone.yaml` | 希望文件小一点 | WMV | 每秒 15 张 | 小 |
| `config.example.high-quality.yaml` | 希望字和画面更清楚 | MP4 | 每秒 30 张 | 大 |

MP4 使用 H.264。程序会先试显卡编码，不行再改由处理器来算。WMV 由处理器来算。画质那一项数字越大，画面越清楚，文件也越大；填 0 时按每秒大约 400 千比特来录。

保存成功后，通知标题是「录屏已保存」，内容是文件名，按钮是「打开所在位置」。点通知正文或这个按钮，效果一样。如果系统通知被关掉了，视频仍会保存，只是没有弹窗。

## 怎么编译

只能在 Windows 10 或更新的系统上用。

自己编译需要两样东西。一是 Go，到 https://go.dev/dl/ 下载安装，版本不能低于项目 `go.mod` 里写的 `go 1.27`。二是能编译 C++ 的环境，因为抓屏和录音那部分是 C++ 写的。最省事的是安装 [w64devkit](https://github.com/skeeto/w64devkit)，解压后用它自带的终端。MSYS2 里的 MinGW 也可以。请用这个环境里的 `make`。

打开终端，进入项目文件夹，执行：

```sh
make
```

完成后，文件夹里会出现 `AutoScreenRecorder.exe`。双击它不会弹出黑窗口。

这一步还会顺便检查配置：如果还没有 `config.yaml`，就从推荐的那份示例复制一份。另外，每次 `make` 都会把 C++ 部分重新编译；没改过的 Go 代码仍用上次的结果，所以不会每次都从零开始。

常用的还有：

```sh
make run      # 编译并马上运行，日志直接打在这个终端里
make config   # 只有还没有 config.yaml 时，才复制推荐配置
make clean    # 删掉编译出来的 exe
make help
```

不用 `make` 时，在同一个终端里执行：

```sh
set CGO_ENABLED=1
set CXX=g++
go build -trimpath -ldflags "-s -w -H windowsgui" -o AutoScreenRecorder.exe ./cmd/autorecorder
```

想确认代码没有问题时：

```sh
go test ./...
```

## 怎么改配置

配置文件叫 `config.yaml`，和程序放在一起，用记事本就能改。第一次可以先复制推荐配置：

```powershell
Copy-Item config.example.balanced.yaml config.yaml
```

程序只在启动时读一次。改完要退出再打开，新设置才会生效。也可以在启动时指定别的文件：

```text
AutoScreenRecorder.exe -config D:\path\config.yaml
```

你自己的 `config.yaml` 不会上传到 Git，仓库里带的是那几份示例。

一份完整配置如下。`watch` 里想再加软件，就按同样的格式添一行。`path_prefix` 一般不用写，只有电脑里有两个同名程序、需要用安装路径区分时才用。

```yaml
mic_trigger:
  watch:
    - name: Lark.exe
    - name: Feishu.exe
    # - name: Zoom.exe
    # - name: Feishu.exe
    #   path_prefix: "D:/Feishu/"
  ignore:
    - SystemSettings.exe

record:
  follow_mouse: true              # true：录鼠标所在的屏幕。false：一直录开始时的那块
  fps: 24                         # 每秒多少张画面，填 1 到 60
  video_bitrate_kbps: 2500        # 画质。越大越清楚，文件越大。0 等于 400
  encode_max_width: 0             # 画面最宽多少像素。0 表示不缩小
  encode_max_height: 0            # 画面最高多少像素。0 表示不缩小
  container: mp4                  # mp4 或 h264 得到 mp4；wmv 得到 wmv

audio:
  enabled: true                   # false：只录画面，不录声音
  system:
    enabled: true                 # 是否录电脑放出来的声音
  microphone:
    enabled: true                 # 是否录麦克风
  gain:
    system_db: 0.0                # 电脑声音大小。0 是原样，负数更小，正数更大
    microphone_db: 0.0            # 麦克风声音大小，同上
  clip_limit: true                # true：声音太大时削掉超出的部分，减轻爆音

output:
  dir: "%USERPROFILE%/Videos/AutoScreenRecorder"   # 视频存哪。%USERPROFILE% 是你的用户文件夹
  template: "{datetime}_{process}.mp4"             # 文件名长什么样

service:
  start_delay_sec: 0              # 占用麦克风后再等几秒才真正开始，不能为负
  stop_delay_sec: 0               # 放开麦克风后再等几秒才停止并保存，不能为负
```

文件名里可以写这些词，程序会换成真实内容：

| 写在文件名里 | 会变成 | 例子 |
| --- | --- | --- |
| `{datetime}` | 开始时间，到分钟 | `202610082222` |
| `{date}` | 日期 | `2026-10-08` |
| `{time}` | 时间 | `22-22-21` |
| `{process}` | 触发这次录制的软件名，不带 .exe | `Lark` |

## 装到电脑上

先编译出 `AutoScreenRecorder.exe`，再双击项目里的 `install.bat`。

安装时会先关掉已经在跑的程序，然后把它复制到：

```text
C:\Users\你的用户名\AppData\Local\AutoScreenRecorder
```

那里还没有配置文件时，会带上一份；已经有了就保持原样，不会盖掉你改过的设置。接着把它设为登录 Windows 后自动启动，并且不弹出黑窗口，然后马上在后台运行一次。以后每次登录，它都会自己起来。

日志和程序放在一起，文件名是 `AutoScreenRecorder.log`。没有开始录、录到一半失败，或者没有通知，先看这个文件的最后几行。安装之后的路径是：

```text
C:\Users\你的用户名\AppData\Local\AutoScreenRecorder\AutoScreenRecorder.log
```

## 卸载

双击 `uninstall.bat`。程序会关掉，开机启动会取消，上面那个安装文件夹也会删掉。

已经录好的视频还在「视频\AutoScreenRecorder」里，或者留在你自己写的那个保存位置。卸载不会删这些视频。

## 这几种情况录不好

- 有版权保护的在线视频，以及一部分全屏游戏，画面可能是黑的。
- 只能录你登录之后看到的这块桌面，录不了其他用户，也录不了登录界面。
- 名单里的软件如果用的不是系统默认麦克风，程序看不到这次占用，也就不会开始录。
- 系统通知关着的时候没有弹窗，文件仍会保存。
- 第一次保存 MP4 时，如果显卡编码暂时起不来，会改用处理器来算，开始前可能要多等一会儿。

## 代码在哪

平时使用不用看这里。要改功能时可以按这个找：

```text
cmd/autorecorder/          程序入口
internal/controller/       决定何时开始、何时停止
internal/config/           读取配置文件
internal/process/          判断占用麦克风的是不是名单里的软件
internal/output/           视频保存路径和文件名
internal/wincap/           抓屏幕、录声音、生成视频文件
internal/notify/           录完后的通知，以及点通知后打开文件夹
internal/applog/           写日志
internal/singleinstance/   保证同时只运行一份
install.ps1 / uninstall.ps1
```
